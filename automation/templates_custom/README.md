Namingo Registrar custom email templates
=========================================

Files placed in this directory override the corresponding templates
from ../templates/.

For example:

    templates/wdrp.txt
    templates_custom/wdrp.txt

If templates_custom/wdrp.txt exists and is readable, it will be used.

Otherwise Namingo Registrar automatically falls back to
templates/wdrp.txt.

Only copy templates that you want to customize.

Files in this directory are local installation files and are preserved
by the Namingo Registrar upgrade process.
